MY 50/50 MONEY MANAGER — PWA PACKAGE

To make Chrome show Install / Add to Home screen, publish these files on an HTTPS host.
Keep index.html, manifest.webmanifest, and sw.js together in the same folder.
After publishing, open the HTTPS website in Chrome, tap ⋮, then Install app or Add to Home screen.

Data is stored locally in that browser on that device. It does not sync automatically.
